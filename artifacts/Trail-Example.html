No map — just the trail
Every ability has a stat-requirement vector, not a fixed spot on a graph. Each level grants one free point to spend on any stat; an ability unlocks (into the existing gold Learn screen, unchanged) the moment its requirement is met. Two heroes below start identical and end up nowhere near each other.

No tree, ring, or map to author at all — each ability just carries a requirement (e.g. Fireball: INT≥8, Lay on Hands: STR≥5 & WIS≥4 for a hybrid). The hero's own pick history is the trail; it only looks like a branch because two heroes who shared a start diverged. This could replace skilltrees.json's whole node graph (GG-T167/GG-T74/GG-T83 become mostly moot) or sit alongside it — worth deciding before any more tree content is authored.
